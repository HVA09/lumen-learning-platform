# Lumen Frontend

واجهة منصّة **لومن** التعليمية — React + Vite + Tailwind CSS + i18next (عربي/إنجليزي، RTL/LTR).

## المزايا

- تسجيل دخول / إنشاء حساب (JWT، متوافق مع الباك اند)، نسيت كلمة المرور، تأكيد البريد،
  2FA بـ QR code
- **مسار التعلّم** (الشاشة الرئيسية): مواد ومواضيع مرتّبة، حالة كل موضوع
  (مقفل/متاح/قيد الدراسة/مُتقَن) والموضوع المقترح تاليًا، بناءً على المتطلبات السابقة
  واجتياز اختبارات البوابة
- **الموضوع**: دروس بصيغة Markdown مع تتبّع الإنجاز، مختبر تفاعلي (محاكاة) لكل موضوع
  يدعمه، واختبار تدريبي أو اختبار بوابة (10 أسئلة، يحتاج 80% للاجتياز) — التصحيح
  وحساب الإتقان يصيران بالكامل في السيرفر
- **بطاقات المراجعة**: مجموعات جاهزة لكل موضوع تُضاف بضغطة واحدة، ثم مراجعة بالتكرار
  المتباعد (SM-2+)
- **الواجبات**: المعلّم ينشئ الواجب (عامًا أو موجَّهًا لفصل محدّد) ويقيّمه يدويًا بنسبة وملاحظات؛ الطالب يسلّم
  إجابة مكتوبة ويشوف نتيجته وملاحظات معلّمه
- **الفصول**: الطالب ينضم برمز دعوة من معلّمه؛ المعلّم ينشئ فصولًا، ينسخ الرمز، يشوف قائمة طلابه ومتوسط
  إتقان كل واحد، يجدّد الرمز أو يزيل طالبًا؛ ولوحة المتصدرين تُصفّى على فصل واحد
- **الرياضيات (KaTeX)**: المعادلات في الدروس والأسئلة والبطاقات تُعرض مصوّرة من صيغة `$...$`، مع إصلاح
  اتجاه العرض في الصفحات العربية (بدونه تنعكس المعادلة: `2x+3=7` تظهر `7=3+2x`)
- **إدارة المحتوى** (معلّم/admin): معاينة حيّة للمعادلات أثناء الكتابة، تبويب **تحليلات** يكشف الأسئلة اللي تحتاج
  مراجعة، وإنشاء وتعديل دروس وأسئلة (اختيار من متعدد، صح/خطأ،
  رقمية، نصية قصيرة) لكل موضوع
- **التحفيز**: لوحة متصدرين (نقاط محسوبة من نشاط تحقّق منه السيرفر)، إنجازات، ومتابعة
  الأيام المتتالية (streak)
- لوحة "تقدّمي": متوسط الإتقان، اختبارات ودروس منجزة، أيام متتالية، مواضيع تحتاج تركيز،
  وإرسال تقرير فوري بالإيميل
- لوحة "الملفات": سحب وإفلات، معاينة، تحميل، حذف
- لوحة "الإدارة" (admin فقط): إحصائيات (طلاب، معلّمون، دروس، أسئلة، محاولات اختبار،
  واجبات) مع رسوم بيانية وتصدير CSV، إدارة أدوار المستخدمين (طالب/معلّم/admin)،
  وسجل تدقيق
- لوحة "الاشتراك": عرض الخطط والخطة المجانية؛ الدفع الإلكتروني معطّل افتراضيًا ولا تظهر إجراءات الدفع حتى تفعيل مزود مدفوع بشكل صريح
- جرس إشعارات فورية عبر WebSocket
- أداء: تحميل كسول (lazy) لكل لوحة — كل وحدة ملف منفصل ما يُحمَّل إلا عند فتحها
- PWA قابل للتثبيت، عربي/إنجليزي + RTL/LTR تلقائي

## التشغيل

```bash
npm install
npm run dev
```

يفتح على `http://localhost:5173`.

## الربط بالباك اند

- `.env.development` فيه `VITE_API_BASE_URL=http://localhost:8000` — يفترض إن الباك اند
  شغّال محليًا عبر `docker compose up` (راجع README الباك اند)
- `.env.production` فيه placeholder — لازم تحطه دومين الـ API الحقيقي وقت النشر
- بعد تسجيل الدخول، يضع الخادم رموز الجلسة في ملفات تعريف ارتباط `HttpOnly`، وتستخدم الواجهة `withCredentials` ورمز CSRF في الطلبات التي تغيّر البيانات. لا تخزّن الواجهة JWT في `localStorage` أو في عناوين URL. في تدفق LTI، تستبدل رمزًا أحادي الاستخدام بجلسة متصفح عبر API.

## البنية

```
src/
  App.jsx                يجمع كل شيء: المصادقة، مسار التعلّم، كل اللوحات
  i18n.js                 نصوص عربي/إنجليزي
  hooks/useDirection.js    تبديل RTL/LTR
  lib/
    api.js                 إعداد axios + إرفاق التوكن + معالجة 401
    authApi.js              تسجيل / دخول
    curriculumApi.js         المواد والمواضيع ومسار التعلّم والدروس
    quizApi.js                بدء وتسليم الاختبارات
    contentApi.js              إدارة الدروس والأسئلة (معلّم/admin)
    srsApi.js                   بطاقات المراجعة والمجموعات الجاهزة
    assignmentsApi.js            الواجبات (إنشاء/تسليم/تقييم)
    gamificationApi.js            لوحة المتصدرين والإنجازات
    reportsApi.js                  تقرير التقدّم
  components/
    LearningPath.jsx        الشاشة الرئيسية: شبكة المواضيع وحالتها
    TopicPanel.jsx            الدروس + المختبر + بدء اختبار
    QuizPanel.jsx               عرض الأسئلة والنتائج
    ContentManager.jsx           نماذج إدارة الدروس والأسئلة
    AssignmentsPanel.jsx          إنشاء/تسليم/تقييم الواجبات
    FlashcardReview.jsx            تصفّح المجموعات + مراجعة SM-2+
    simulations/                    خمس محاكاة تفاعلية (رياضيات، فيزياء، بايثون)
```
