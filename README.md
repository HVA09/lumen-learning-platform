# Lumen Learning Platform

مستودع خاص لتطوير منصّة لومن التعليمية.

## بنية المشروع المستهدفة

- `frontend/` — React + Vite
- `backend/` — FastAPI + PostgreSQL

## حالة الاستيراد

ملفات المشروع الأصلية لم تُستورد بعد. بعد رفع الأرشيفين `imports/ai-frontend.zip` و`imports/ai-backend.zip`، سيجهّز سير العمل فرعًا وطلب دمج يحتويان على ملفات المصدر بعد استبعاد ملفات البيئة المحلية والأسرار المحتملة.

## قاعدة التطوير

لا تُعدّل نسخة الإنتاج مباشرة. تُنفّذ الإصلاحات في فرع منفصل، وتُراجع نتائج الاختبارات قبل دمج أي تغيير في `main`.

## الأمان

لا ترفع ملفات `.env` الحقيقية أو مفاتيح API أو بيانات قواعد البيانات أو النسخ الاحتياطية. احتفظ بالقيم الحقيقية في إعدادات بيئة التشغيل فقط.
