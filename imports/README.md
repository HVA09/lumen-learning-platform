# رفع ملفات المصدر للاستيراد الأولي

1. نزّل ملفي ZIP المرفقين في محادثة ChatGPT إلى جهازك.
2. افتح هذا المجلد في مستودع GitHub الخاص.
3. اختر Add file ثم Upload files، وارفع الملفين بالاسمين الدقيقين:
   - `ai-frontend.zip`
   - `ai-backend.zip`
4. نفّذ Commit changes على الفرع `main`.

بعد رفع الأرشيفين، سيشغّل GitHub Actions فحصًا للاسم والمسارات والملفات الحساسة المعروفة، ويستبعد ملفات `.env` المحلية، ثم يفتح Pull Request لاستيراد المصدر إلى `frontend/` و`backend/`. راجع نتائج التشغيل وطلب الدمج قبل الموافقة. لا ترفع أي أسرار أو قواعد بيانات أو نسخ احتياطية.
